## 2. نتائج القياسات الفعلية في المتصفح (Headless Chromium)

### أ) قياسات المهمة 2 (قاعة الأسئلة بلا Scroll على جميع المقاسات):
- **`1920×1080` (شاشة عرض كبيرة)**: `scrollHeight = 1080px` (`zeroPageScroll = true`)، الشريط العلوي `bottom = 86px`، بطاقة السؤال `98px..258px`، شبكة الاختيارات مباشرة أسفلها `270px..984px`، شريط تحكم المعلم السفلي `996px..1068px`.

- **`768×1024` (تابلت)**: `scrollHeight = 1024px` (`zeroPageScroll = true`)، جميع الاختيارات الأربعة وشريط التحكم السفلي (`bottom = 1013px`) داخل حدود الشاشة بالكامل.
- **`390×844` (هاتف — شاشة المعلم وشاشة الطالب)**:
  - شاشة المعلم (عمود واحد للاختيارات): `scrollHeight = 844px` (`zeroPageScroll = true`)، الاختيار الرابع `bottom = 669px`، شريط التحكم السفلي `bottom = 835px`.
